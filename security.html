Security & Architecture

Built For Confidential Matters.

Privileged documents and Bates-numbered productions demand more than a shared folder. Exhibit Binder Studio isolates every organization's data and records everything that happens to it.

Isolation by design

Every organization's documents are separated at the database level with row-level security: one firm's documents are never returned in another firm's queries, independent of application code.

Permanent redaction

Redaction removes content; it doesn't hide it. Once committed, the underlying text, images, and vector graphics are gone from the file, irreversible by design.

Full audit log

Every mutating action (upload, compile, export, share, invite, delete) is captured with actor, timestamp, and before/after state.

US data residency

Documents are stored in US-only storage today, with a routing mechanism ready for additional regions.

Granular access control

Custom organization roles and API keys let you decide exactly who can view, edit, export, or share each matter.

Enterprise sign-on

Single sign-on via Microsoft Entra is available for enterprise teams that manage access centrally.
